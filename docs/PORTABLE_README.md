# Xpet 3D 桌面宠物

Xpet 是 Windows 3D 桌面宠物，支持角色互动、聊天、语音、模型导入和记忆。便携程序包含运行所需组件，无需安装 Unity、Python 或 Blender。

## 启动

解压整个发行文件夹，双击根目录的 **Xpet.exe**。请保留完整文件夹；只复制一个 EXE 无法运行。

默认只显示角色。**右键角色**打开菜单，进入聊天、设置、语音输入或退出；系统托盘也提供显隐和退出操作。按 **Ctrl+Alt+P** 可显示或隐藏宠物。

## 配置与使用

- 在“设置 → 对话”选择服务类型，填写接口地址、模型名称和密钥，再测试连接。没有配置聊天接口时可使用明确标识的离线体验。
- 聊天按 **Enter** 发送，**Shift+Enter** 换行。语音识别与朗读可在“语音”页分别设置。
- “角色卡”管理人物设定和外观；“模型导入”可导入获授权的模型。可用角色以当前发行包为准。
- “动作管理”管理内置、组合和导入动作；“工具 → 技能书”管理角色的文字指导。
- “记忆”页可启用聊天记录和长期记忆，两个开关默认均关闭。
- 屏幕分析需要支持视觉的模型。“主动看屏幕”默认关闭，开启后会按设置把屏幕内容发送给所选服务。电脑操作建议需要确认，并受应用白名单限制。

模型导入主要适配可识别的人形骨骼。VMD 目前支持兼容骨架的 FK 动作，不支持完整 IK、镜头轨道或原始 MMD 刚体物理；复杂服饰与材质可能需要进一步适配。
