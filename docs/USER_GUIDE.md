# Xpet 使用指南

Xpet 是 Windows 3D 桌面宠物，支持角色互动、聊天、语音、角色卡、模型导入和记忆。

使用便携程序时，解压完整发行文件夹并双击 **Xpet.exe**，无需安装 Python、Unity 或 Blender。从源码构建请先阅读[开发指南](DEVELOPMENT.md)：源码不附带 3D 模型，完整客户端需要准备获授权的角色资源。

## 桌面交互

- **右键角色**打开菜单，进入聊天、语音输入、设置或退出。
- 拖动角色可调整位置；按住手掌约 0.28 秒可以牵手，快速拖动切换为跑动，向上拉可提起角色。
- 点击角色不同部位会触发相应反馈。动作与表情取决于角色骨骼和当前可用动作。
- 系统托盘支持显隐、聊天、设置、低功耗和退出；**Ctrl+Alt+P** 显示或隐藏宠物。
- “设置 → 外观”可调整人物大小、背景、鼠标注视、驻留显示器和休息行为。

## 聊天与接口

聊天窗口按需展开。**Enter** 发送，**Shift+Enter** 换行；处理中可点击停止，中止回复与朗读。收起聊天后，简短回复显示在角色头顶气泡中。

在“设置 → 对话”选择服务并填写参数，点击“测试连接”检查配置：

| 服务 | 配置方式 |
| --- | --- |
| OpenAI 兼容 | 服务商提供的 Base URL、模型名称和密钥 |
| Anthropic / SystemOne | Messages 兼容接口地址、模型名称和密钥 |
| Ollama | 已启动的 Ollama 服务地址和已安装的模型名称 |
| 离线体验 | 无需配置，使用内置互动回复 |

离线体验不调用大模型。视觉、语音和工具调用能力由所选模型与服务决定。

“工具 → 技能书”可启用、编辑或导入 Markdown 技能。技能为角色提供文字指导，不执行文件中的程序。动作指令会按当前可用动作验证；支持工具调用的模型也可选择合适动作。

## 角色卡与外观

“设置 → 角色卡”管理人物名称、人设、模型、动作和语音配置，可新建、编辑、复制和切换角色卡。

每张角色卡最多可配置 32 套皮肤。先导入模型，再添加皮肤并选择对应模型；换装保留当前人物设定、语音和对话。“大模型自动换装”允许模型从角色卡已有皮肤中选择，可单独关闭。

当前角色卡使用项目格式，暂不支持酒馆 PNG 角色卡导入。

## 角色模型库

在“设置 → 模型导入”选择 `.pmx`、`.fbx`、`.glb` 或兼容的 `.petmodel` 文件。单个源文件上限为 **1 GB**；模型使用外部贴图时，应保持贴图相对目录完整，单张贴图不能超过 **64 MB**。

PMX、FBX 和 GLB 在运行时解析，无需 Blender 或 Unity 编辑器。导入进度和失败原因显示在页面中；切换失败时保留当前外观。导入和使用素材前需取得相应授权，见[素材说明](ASSETS.md)。

目前主要适配可识别的人形骨骼。复杂游戏材质、任意骨架及原始 MMD 刚体物理无法保证还原；衣裙、头发和配饰使用受限的次级运动。

## 动作与表情

“设置 → 动作管理”可预览、启用和关闭动作，也可创建由多个动作组成的组合。组合支持 **1–8 步**，每步 **0.5–10 秒**，速度为 **0.5–2 倍**。

VMD 导入支持 **VMD 0002**，上限 **32 MB、3 分钟**。当前播放兼容骨架的 FK 骨骼旋转和受限中心高度变化，不执行足 IK、镜头或表情轨道；依赖 IK 的舞蹈需要先烘焙为 FK。FBX 动作文件暂不支持。

表情、眨眼和口型使用角色提供的骨骼或形变。行走、跑步、跳跃、牵手及触摸反馈的效果取决于模型适配情况。

## 语音

“设置 → 语音”可分别配置语音识别和朗读：

- 识别支持 OpenAI 兼容的 `/audio/transcriptions` 接口与 Windows SAPI。
- 朗读支持 Edge、OpenAI 兼容接口和 GPT-SoVITS；GPT-SoVITS 使用 `api_v2.py` 的 `/tts` 接口。
- 点击语音输入开始录音，再次点击停止，最长 **30 秒**；识别成功后发送聊天。
- “全局按住说话”默认关闭，默认快捷键为 **Ctrl+Alt+V**，可以修改。
- 唤醒词默认关闭，开启后需要可用麦克风与 Windows 语音语言支持。

开启朗读时，文字在音频开始播放后显示，口型随音量变化；语音失败时仍会显示文字并提示原因。

## 聊天与记忆

“设置 → 记忆”中的“保存聊天记录”和“启用长期记忆”是两个独立开关，默认均关闭。

启用聊天记录后可新建、打开和继续会话。长期记忆用于检索明确保存的资料，也支持通过“记住……”提出记忆请求。记忆可按“用户资料”和“角色自身”分别管理；摘要与 Markdown 文档需要点击各自的保存按钮。

## 屏幕与文件

聊天工具栏的“本次屏幕”只对下一条手动发送生效，需使用支持视觉的模型。拖入图片或文本文件也可交给所选模型分析，具体格式限制见[后端说明](../pet-backend/README.md)。

“工具 → 主动看屏幕”默认关闭。开启后按设定间隔向视觉模型发送屏幕内容，间隔为 **30–900 秒**，默认 **90 秒**；聊天、录音、朗读、拖拽或打开面板时暂停。模型可以保持安静或给出简短回应。

电脑操作建议需要在设置中启用对应功能，并由用户确认执行；当前只支持白名单应用和 HTTP / HTTPS 网址，不执行任意生成的脚本。
